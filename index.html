Como entrar

Três passos, menos de um minuto.

Funciona tanto no Java quanto no Bedrock. Sem mods obrigatórios.

PASSO 01

Abra o Minecraft

Java Edition 1.20+ ou Bedrock Edition. Ambos usam o mesmo IP, com portas diferentes.

PASSO 02

Adicione o servidor

Java: cole sweetmc.xyz
Bedrock: cole sweetmc.xyz e porta 19132.

PASSO 03

Entre e jogue

Sem whitelist, sem senha. Escolha seu nickname, leia as regras e comece sua jornada.

Dúvidas

Perguntas frequentes.

Não achou sua resposta? Chama no Discord que a gente responde em minutos.

O servidor é pago ou tem pay-to-win?
Não. O servidor é 100% gratuito e não possui vantagens pagas que quebrem o equilíbrio. Doações rendem apenas cosméticos e benefícios visuais.
Quais versões são suportadas?
Java Edition 1.20 até a versão mais recente, e Bedrock Edition também é suportada através da porta 19132. Basta usar o mesmo IP.
Preciso instalar mods?
Não. Todos os recursos funcionam direto no cliente vanilla. Mods opcionais (como minimapa) são permitidos desde que não deem vantagem competitiva.
Perco meus itens se ficar offline muito tempo?
Não. Seus itens, terrenos e progresso ficam salvos indefinidamente. Recomendamos entrar pelo menos uma vez por mês para evitar limpeza de bases inativas.
Como faço para reportar um jogador?
Use o comando /report dentro do jogo ou abra um ticket no nosso Discord. Nossa equipe responde em até 24h.
